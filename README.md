# Srinija Challagali – Portfolio

Personal developer portfolio, a single-page site built with HTML, CSS and a little JavaScript and hosted on GitHub Pages.

## Sections

- **Hero** – an animated terminal summary of skills and credentials
- **About** – background, education and focus areas
- **Skills** – languages, machine learning and computer vision, testing and tools
- **Projects** – Image Tampering Detection, Face Emotion Detection and Flight Booking System, each linked to its repository
- **Journey** – training, education and hackathons
- **Certifications** – IBM, Infosys, Qspiders and Oracle
- **Contact** – contact form powered by Web3Forms

## Structure

```
index.html     The portfolio page
styles.css     Styles (dark developer theme, responsive down to mobile)
main.js        Terminal typing animation (skipped when reduced motion is on)
assets/img/    Portrait, project images and hackathon logo
assets/icons/  Technology logos from Devicon
```

## Run locally

Open `index.html` in any browser. No build step is needed.
