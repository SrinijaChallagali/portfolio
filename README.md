# Srinija Challagali – Portfolio

Personal portfolio website built with HTML and CSS, hosted on GitHub Pages.

## Pages

- **About** – introduction, skills and certifications
- **Resume** – embedded resume with a PDF download
- **Projects** – featured projects linking to their GitHub repositories
- **Contact** – contact form (powered by Web3Forms)

## Run locally

Open `index.html` in any browser. No build step is needed.
