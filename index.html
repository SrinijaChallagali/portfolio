Image Tampering Detection

Checks whether a photo has been edited, combining image forensics, a machine learning classifier and a web app.

  • Five OpenCV forensic techniques: copy-move detection, noise analysis, JPEG compression artifacts, lighting consistency and edge artifacts.
  • Random Forest and SVM classifiers trained on 22 extracted image features.
  • Streamlit app that scores uploaded images on blur, sharpness, noise and compression quality.

Face Emotion Detection

Recognizes seven emotions on faces in a live webcam feed.

  • CNN trained on 28,800+ face images, reaching about 62% validation accuracy across 7 emotions.
  • Batch normalization, dropout, early stopping and learning-rate reduction to limit overfitting.
  • OpenCV Haar cascades find faces in each frame before classification.
  • Python
  • TensorFlow
  • Keras
  • OpenCV
